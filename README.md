# VidyaVerse

Learn. Visualize. Practise. Master.

VidyaVerse is an AI-powered interactive and multilingual
education platform designed initially for Indian students
and parents.

## Product Capabilities

- Interactive educational content.
- Visual learning engines.
- AI-generated questions and explanations.
- Examination paper uploads.
- Personalized practice.
- Multilingual learning.
- Parent progress dashboards.
- Live examinations.
- Educational competitions.

## Technology

- Node.js
